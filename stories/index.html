我一直描述不出来的东西是……
The thing I can never describe is…

观众接着这句话写下的答案，和一个程序照着画的图。程序只看过展厅里的十一段影像，画出来的是它的猜测，跟写的人心里那幅多半不一样。
Answers written by visitors, and the picture a program drew from each. The program has only seen the eleven films, so what it draws is its guess, and probably not what the writer had in mind.
